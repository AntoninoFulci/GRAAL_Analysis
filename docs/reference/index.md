# Scientific reference evidence

This directory preserves historical Fortran and dated research/source audits. These records describe the code, measurements and limitations at their stated dates; old commands and archived plan links are evidence, not current operating instructions. Use the [current wiki](../../wiki/Home.md) and [scientific status](../../wiki/status.md) for operation and unresolved work.

`fortran/` contains the original central/forward track classifiers. `research/` contains dated literature, background, charged-channel, Dalitz and uncertainty investigations. The finite-bin audit records its original 9 October verification; the current explanation and citation are in the [wiki](../../wiki/finite-bin-correction.md).

Original pre-relocation document bytes and bibliography manifests are preserved under local `results_test/repository-refactor-20261023/task-9/archive/`, indexed by that task's preservation manifest. Historical source-code/document SHA values identify the original audited revisions, not automatically the current files. Original PDF SHA values remain unchanged and are checked against the bibliography; the PDFs are in `docs/papers/`. Current machine-readable model references remain in `09_theory/references/`.
