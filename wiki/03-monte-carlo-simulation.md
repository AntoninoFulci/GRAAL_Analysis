# Stage 03: simulation and geometry

[Generators](https://github.com/AntoninoFulci/GRAAL_Analysis/blob/main/03_mc_simulation/generators) and the [channel registry](https://github.com/AntoninoFulci/GRAAL_Analysis/blob/main/00_common/physics/channels.py) define the signal and background channels, physical production thresholds, masses, branching fractions and detector-smearing assumptions. The workflow generates only channels kinematically open in the requested beam window. Seeds and thread assignment are explicit; a stage-label rename must not change them.

The event model uses simplified smearing and photon loss for BDT training. It does not establish full detector acceptance, trigger efficiency or background normalization. [Stage 04](04-bdt-training) folds the beam spectrum and channel weights into the training sample.

GEANT4 work is separate in [03_mc_simulation/geant4](https://github.com/AntoninoFulci/GRAAL_Analysis/blob/main/03_mc_simulation/geant4). The preserved GEANT3 profile is GRAAL_26, old cylinders, new planar chambers, Catania disks and a 6.12 cm deuterium target. Its [geometry snapshot](https://github.com/AntoninoFulci/GRAAL_Analysis/blob/main/03_mc_simulation/geant4/reference/geometry.g3) and [manifest](https://github.com/AntoninoFulci/GRAAL_Analysis/blob/main/03_mc_simulation/geant4/reference/manifest.json) identify the original sources and libraries.

The dated 23 October geometry audit reports 98,685 queries covering 858 occupied physical identities, no medium/path differences, no overlaps above 0.001 mm, and GDML reopening checks for 16 materials. These are sampled geometric checks. Transport, physics list/cuts, material physics, response, trigger, digitization, acceptance and the analysis event contract remain open.

The native GUI helper is `bash 03_mc_simulation/geant4/view_native.sh`; run it only in a graphical session with its Spack GEANT4/Qt environment available. Its default generated build is `results_test/build/graal-geant4-viewer`. Build any numerical converter under a separate `results_test/<campaign>/build/` with CMake source `03_mc_simulation/geant4`. The helper uses the certified GDML and display macros without rewriting the geometry source. See [status](status) for validation boundaries.
